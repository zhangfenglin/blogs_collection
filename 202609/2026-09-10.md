### 1. DeepSeek 开启 V4.1 Flash 中间版本内测：官方称新结构、原生多模态，邀测代号 9 月 10 日到期
- 类型：工程
- 来源：微信公号「字母AI」（苗正，钛媒体 / 36氪授权转载，2026-09-09）
- 发布日期：2026-09-09（邀测窗口写到 9 月 10 日）

- 阅读置信度：全文（钛媒体稿）；速度倍数与 token/s 为社区实测经该稿转述，官方无技术报告、无评测表

  - 调用价格该稿写与 V4 Flash 相同。无官方价目页截图

- 关键数据/指标：0.3 秒 / 159.3 token/s / 0.8 秒；420 / 409.5 token/s；5.2×–6.0×。均为字母AI转述社区实测。150 人为招聘名额

### 2. Meta 上线个人 Agent Muse：每人一台云端 Secure VM，Sentinel 审查外发动作
- 类型：产品 / 行业
- 来源：微信公号「AI前线」（冬梅，36氪授权转载，2026-09-09）；对照财联社 2026-09-10、路透社 2026-09-08
- 发布日期：美国当地时间 2026-09-08；中文稿 9/9–9/10
- 链接：https://eu.36kr.com/zh/p/3975709340004873
- 阅读置信度：全文（AI前线对路透 / CNBC / Alex Heath 采访的整理）；抽成商业模式是扎克伯格长期设想，不是已公布的分成比例
- 一句话：Meta 把内部项目 Hatch 做成消费级个人 Agent「Muse」。底层模型 Muse Spark 1.3。美国 18 岁及以上用户可通过独立 App、网页 Muse.ai、WhatsApp 使用；后续进 AI 眼镜。用户给出目标后，Agent 在独立云端虚拟机里继续跑，退出应用也不停。
- 中心思想：和 ChatGPT / Gemini / Meta AI 聊天助手的差别，按扎克伯格的说法，是模型后面多了一台可被 Agent 控制的虚拟计算机。产品卖点写成安全和隐私，而不是再发一张跑分表。
- 关键要点：
  - 能力例子：收发邮件、订机票酒店、买电影票、约网球课、填家长同意书、账单谈判、把 Instagram 收藏食谱变成购物清单。接入 Ticketmaster、OpenTable、Gmail、Google Calendar、Google Drive
  - 架构：Muse 提目标和动作；另一套独立系统 Sentinel 审查访问互联网或外发信息，判定直接执行、阻止、或必须用户批准。支付走 Stripe Link 一次性卡号，Muse 看不到真实卡号；1Password / Shop Pay 后续接入
  - 当前 Secure VM：公司政策禁止拿数据做广告，高管承认技术上 Meta 仍可能访问。计划今年晚些时候上 Confidential VM（可信执行环境，密钥在用户设备）
  - 价格（Alexandr Wang 对 CNBC）：免费档，或按用量每月 20 美元 / 100 美元。扎克伯格：上线初期每周约 1 亿 Token 免费额度，并配独立虚拟机
  - 路透：产品原考虑 4 月发，因安全推迟；Vishal Shah 称达到向消费者开放的「最低门槛」，无法保证永远不出错
  - 财联社：消息公布后 Meta 股价周三盘中一度涨超 7%，最高 657.86 美元（该稿）
- 关键数据/指标：每周约 1 亿 Token（扎克伯格口述）；订阅 20 / 100 美元（Wang）；涨超 7% / 657.86 美元（财联社）
- 技术或产品细节：无对外模型字符串写在这篇产品稿里。调用面是 App / Web / WhatsApp，不是 Meta Model API 的新 endpoint。敏感操作前确认；应用读写权限可按任务、交易或时间段授予
- 开发者可带走：做长期 Agent 先分三层：独立计算环境、持久记忆、监督进程（谁有权点「发送 / 付款」）。不要把「退出 App 还能干活」和「模型更强」写成同一件事。支付不要让模型接触真实卡号
- 边界与风险：Confidential VM 未上线，当前隐私承诺是政策加审计，不是硬件级隔离。交易抽成未定量。美国以外不可用。Wang 自己的使用案例不能当成功率
- 为何重要：消费级个人 Agent 第一次按「一人一虚拟机 + 监督模型」出货，而不是再做一个聊天窗口

### 3. 蚂蚁 inclusionAI 开源 Ling-3.0-flash-VL：124B-A5.5B，视觉编进推理与工具调用
- 类型：工程
- 来源：Hugging Face 模型卡 `inclusionAI/Ling-3.0-flash-VL`；中文对照 9 月 9 日多家转载（ITCOW / 17173 等，口径来自公司通稿）
- 发布日期：中文通稿 2026-09-09；权重页未在通稿写死上传时刻
- 链接：https://huggingface.co/inclusionAI/Ling-3.0-flash-VL
- 阅读置信度：全文（模型卡）；「Image-to-WebDev 超过 GPT-5.4」只出现在二手游戏站转载，模型卡没有，不采用
- 一句话：蚂蚁百灵系列给出第一款原生多模态权重 Ling-3.0-flash-VL。总参 124B，每 token 激活 5.5B；支持图像 / 文本 / 视频。模型卡引言写上下文 256K，Overview 写最高 1M（YaRN）；SGLang 示例把 `context-length` 设为 262144。
- 中心思想：不是在纯文本 Ling-3.0-flash 上外挂一个 caption 模型。ViT + 两层 MLP 投影 + VideoRoPE，再接到原来的 42 层混合主干（KDA 与 Gated MLA 按 5:1 交替）。公司把视觉写成理解、推理、行动、校验整条链的输入，而不只是「看图说话」。
- 关键要点：
  - Artificial Analysis Intelligence Index v4.1.1：VL 为 42 分，纯文本 Ling-3.0-flash 为 38 分（模型卡，+4）。这是综合指数，不是某一项视觉榜
  - 模型卡把能力拆成 Understand / Reason / Act 三块：复杂版面与文档、带视觉证据的多步推理、看界面再变成动作序列
  - 默认 thinking；推荐采样 `temperature=0.6, top_p=0.95, top_k=20`。Terminal-Bench 2.1 按 AA 协议、Terminus 2、2 小时超时、preserve-thinking、每题 3 次取均值；解码 `temperature=1.0, max_new_tokens=32K`，256K 上下文。具体分数模型卡这段未列出数字
  - 许可：MIT（第三方模型目录与 HF 页一致）。BF16 主权重；另有 `Ling-3.0-flash-VL-fp8` / `-fp4`。中文通稿写 FP4 / INT4「计划近期」——HF 上 FP4 仓库已出现，以仓库为准
  - 体验：Ling Studio 免费（通稿）。推理：`lmsysorg/sglang:dev-Ling-3.0-flash-VL`，4×141GB 级或 8×80GB；vLLM 走 `inclusionAI/vllm-ling-v3` 的 `--tool-call-parser ling3 --reasoning-parser ling3`
- 关键数据/指标：124B / 5.5B；AA 指数 42 vs 38；原生位置编码 131,072（YaRN 配置里的 `original_max_position_embeddings`）
- 技术或产品细节：视频输入用 `video_url`。思考默认开，请求里 `"chat_template_kwargs": {"enable_thinking": false}` 可关。架构名 `BailingMoeV3VLForConditionalGeneration`（vLLM recipes）
- 开发者可带走：已在跑 Ling-3.0-flash 文本的，VL 是同一套 MoE 经济学加眼睛。先用 SGLang cookbook 的 256K 配方，不要一上来开 1M。GUI / 前端生成要自己准备截图回归，不要引用游戏站对 GPT-5.4 的对比
- 边界与风险：引言 256K 与 Overview 1M 不一致，生产按实际 `max_position` 和 YaRN 因子验收。通稿「视觉反馈闭环」是中文营销句，模型卡对应的是 Act / verification，没有单独模块名。Image-to-WebDev 数字未进模型卡
- 为何重要：开源侧又多了一个 5.5B 激活、可商用的原生多模态 MoE，和文本 flash 共用 serving 栈

### 5. Google DeepMind 发布 AlphaGenome Atlas：预计算约 90 亿个单碱基变异的分子效应，数据集约 1 PB
- 类型：工程
- 来源：Google 官方博客（2026-09-08）；DeepMind 科学博客；微信公号「新智元」（36氪转载，2026-09-09）；对照 Ars Technica 2026-09-09
- 发布日期：官方 2026-09-08；中文与 Ars 9/9
- 链接：https://blog.google/innovation-and-ai/models-and-research/google-deepmind/alphagenome-atlas/
- 阅读置信度：全文（Google / DeepMind 博客）；新智元「240 万亿预测值」「285 年」「80 倍」为该公号推算或转述，官方博客未写这三项
- 一句话：DeepMind 用已有 AlphaGenome 模型，把人类基因组每个位点三种可能替换（约 90 亿个单核苷酸变异）的调控效应预计算成一张可查询图，体积约 1 PB，官方称超过 AlphaFold 数据库约 30 倍。非商业用途即日起网页可查；商业用途「很快」上 Google Cloud。
- 中心思想：以前要对某个变异现跑模型；现在变成查表。AVI（AlphaGenome Variant Impact）把 AlphaGenome 的调控预测和 AlphaMissense 的错义致病性收成一个数，编码区和非编码区共用。官方页底部写明：不是医疗建议，未批准临床使用。
- 关键要点：
  - 入口：网页门户（官方称无需写代码）、AlphaGenome API、Google Antigravity 里的 skill
  - 内容分层（DeepMind 博客）：每个变异的分子效应预测（人类和小鼠、数百种细胞类型 / 组织）；AVI 分数；AVI 特征归因（剪接、染色质可及性、表达等）；以及一套反复出现的 DNA motif（DeepMind 写「over 2,500」；新智元写 2601 个模式、2530 亿个实例——后两个数字只在公号出现）
  - Broad / GREGoR：Laura Covill 与 Anne O'Donnell-Luria 用 AVI 给未解罕见病候选变异排序，把 DNM1 内含子一个 G→A 排到前面；模型预测它制造了错误剪接位点、蛋白异常延长，随后湿实验验证（官方案例）
  - 埃克塞特 Gareth Hawkes：>54,000 名 UK Biobank 全基因组，按预测分子效应分组后，非编码关联多发现 22%；聚焦影响最大的 1% 非编码变异，识别 19 个与 BMI 相关的遗传区域（官方）
  - Ars Technica：系统目前限小鼠和人类、训练细胞类型有限；很多预测也可能从 ENCODE 训练数据里直接读出，外推到尼安德特 / 丹尼索瓦或未覆盖细胞类型「尚不清楚是否已经做得到」
- 关键数据/指标：约 90 亿变异；约 1 PB；约 30× AlphaFold DB；+22% 非编码关联；19 个 BMI 区域。均为官方或合作者口径。新智元的 27,000 条/变异、240 万亿、80 倍流水线加速，待用 DeepMind 长文核对
- 技术或产品细节：基座模型学术用途已在 GitHub 与 API；Cloud Model Garden 可商用基座。Atlas 网页非商业、Cloud 商用「soon」。Antigravity skill 把查位点、排序、画结构接进 Agent 工作流
- 开发者可带走：做基因组 Agent 先接官方门户 / API / Antigravity skill，不要本地重跑 1 PB。AVI 用来排优先级，湿实验验证仍是必要步骤。产品文案必须带「非临床」
- 边界与风险：穷举的是参考基因组上的单碱基替换，不是每个真实人体内的 indel / 结构变异。临床使用未批准。公号「破解生命天书」是标题，官方用语是 predictive map
- 为何重要：继 AlphaFold 数据库之后，DeepMind 又把一个「对单个样本现推理」的模型，变成全基因组可检索的静态资产
