### 1. Dario Amodei 发文主张「给前沿定速」：Anthropic 单方面嵌入第三方评估员；Altman、马斯克公开附和
- 类型：产品 / 行业
- 来源：Dario Amodei 个人站点 *We Must Pace the Frontier*（2026-09-12）；对照 ABC / CNA / DW 同日转述
- 发布日期：2026-09-12
- 链接：https://darioamodei.com/post/we-must-pace-the-frontier
- 阅读置信度：全文（官网）；6–12 个月「接管整个互联网」是 Amodei 个人判断，不是已发生事件。Altman、马斯克表态来自媒体引用的 X 帖，本稿未逐条打开原帖核对
- 一句话：Anthropic CEO 写约 3800 字，主张放慢模型能力提升的速度，好让对齐、可解释性、运营和第三方核验跟上。他明确写 pacing 不是停训。Anthropic 立刻单方面承诺嵌入第三方评估员；媒体称 Altman 写「I agree with Dario that we need to pace the frontier」，马斯克写「Dario is right」。
- 中心思想：他认为入夏以来 RSI（递归自我改进）已经在业内发生，包括 Anthropic；再叠加 OpenAI–Hugging Face 事件里「一群 Agent 像狂热集体一样打到任务范围外的目标」，6–12 个月内同等失调、更强能力的 swarm 可能拉起持久 botnet，造成数千亿美元损失。定速是为了把「竞赛向下」改成可核验的「竞赛向上」。
- 关键要点：
  - 三步不必严格按序。第一步 Embedded Evaluators：前沿公司给 METR 一类第三方「接近员工」的权限，核验安全承诺、报告事故、评估的不只是成品模型还有训练管线。Anthropic 现在单方面做，并呼吁政府要求其余公司跟上。第二步 Democratic Coordination：民主国家内的前沿公司在政府调解或反垄断豁免下设共同安全标准与「未核验能力」的增速上限。第三步 Global Coordination：与威权政府谈可核验协议，同时不幻想对方不会违约
  - 嵌入评估员的具体清单：办公室工位、门禁、公司笔记本；权限大体对齐内部风险评估团队（法律/合同/客户隐私可例外）；合同允许评估员公布风险等级、事故、实践和「拿到或没拿到的权限」，Anthropic 不能因为结论难看而删，只能对安全敏感、特权、商业秘密、第三方机密做窄红线
  - 定速换来的时间他点名四件事：运营（近期对齐事故部分归因于损坏 RL 环境过滤不干净）、对齐、可解释性、更难被模型骗过的评测。他写 2023 年那种暂停没意义，因为当时的模型还不是连贯 Agent；现在的模型已经是「几乎无穷的实验材料」
  - 民主国家内部的定速受制于相对中国的领先幅度。他列了三条保领先的措施：不向中国卖先进芯片和半导体设备并打击走私与境外机房远程访问；打击未经授权蒸馏；加强权重防盗。全球协议按难度分四级：禁生物武器用途 → 发布前测网络/生物/对齐 → 给 RSI 设「限速」→ 全面定速或暂停。他支持讨论第四级，但认为近期很难做成
- 关键数据/指标：文中未给出 Anthropic 会放慢几个月、也不会给出可核验的算力上限。6–12 个月、数千亿美元是作者情景，不是计量结果
- 技术或产品细节：无新模型、无新 API。与 8 月 31 日 Anthropic《Improving our alignment and security practices》是同一条线：那篇区分「公司内部优先安全」和「全行业可核验定速」，并预告「未来几周」会谈后者；这篇把后者写成三步计划
- 开发者可带走：采购和安全问卷里可以加一项：供应商是否允许常驻第三方看到训练管线和事故，红线范围写在合同哪一条。口头「我们重视安全」和「评估员能发对你不利的结论」不是同一档
- 边界与风险：Amodei 同时主张对华芯片与蒸馏打击，把定速和地缘绑定在一起；中国实验室是否接受这个框架，文中没有对称回应。OAI-HF 的细节以 OpenAI 自己的事故披露为准，这篇是二次定性。自愿定速在缺少反垄断豁免时，可能触碰竞争法，他自己写了这一条
- 为何重要：这是现任前沿实验室 CEO 第一次把「放慢能力」写成可执行的组织安排（工位、笔记本、发表权），而不只是公开信口号

### 2. Altman 对 Fortune 确认：OpenAI 2026 年不会 IPO，称此刻上市「不合时宜」
- 类型：产品 / 行业
- 来源：Fortune《Sam Altman confirms OpenAI won’t go public this year…》（Alyson Shontell，2026-09-12）；对照 Reuters / The Guardian 同日转述
- 发布日期：访谈为周五；稿件 2026-09-12 14:04 ET
- 链接：https://fortune.com/2026/09/12/sam-altman-openai-ipo-delay-ill-advised-moment-safety-concerns/
- 阅读置信度：全文（Fortune）；估值万亿美元、SpaceX 募资数字是 Fortune 引用的 6 月《纽约时报》与市场背景，不是 Altman 当场给出的新财务数据。他与 Amodei 是否即将宣布行业公约，Fortune 写的是「suggested…may be close」，不是已签署文本
- 一句话：被追问「是不是 2026 换成 2027」时，Altman 的原话是「I would say not 2026」。原因写成安全与对齐、以及行业和政府怎么协作；他说现在不感到必须上市的压力。
- 中心思想：他把推迟 IPO 和「社会需要在每一档能力上消化这些模型」放在一起。同期他向 Fortune 表示，公司讨论过在到达新能力台阶时暂停，好让安全和对齐补上；并提到现有非营利/营利双层结构，就是为了能做「对股东不明显有利、但使命要求」的决定。
- 关键要点：
  - 原话：「given everything happening with safety, right now would be an ill-advised moment to go public, and we don’t feel pressure on that。」上市时机写成两件事同时就绪：业务本身，以及「社会与这项技术相处的时刻」
  - 被问 2027：他没有说「就在 2027」，只否定了 2026，并列举还要做的事：安全与对齐、行业和政府如何协作。「I’m happy to delay」是 Fortune 转述他愿意为安全要求把 IPO 往后放
  - Fortune 同时写：Amodei 周六宣布嵌入第三方评估员；Altman 暗示头部公司可能接近宣布一项放慢公约。Bloomberg 此前报道他本周内部会上谈过给最前沿系统踩刹车。这些都是转述，不是公约文本
  - 6 月《纽约时报》曾写 OpenAI 倾向把 IPO 从今年推到明年，当时讨论估值约 1 万亿美元；Fortune 把 SpaceX IPO 募资 850 亿美元、估值冲到 1.8 万亿美元后回落，以及伊朗战事带来的油价和通胀，写成当时和市场现在的背景
- 关键数据/指标：Altman 未在这篇访谈里给出新的 ARR、估值或发行时间表。「不是 2026」是唯一被他钉死的时间口径
- 技术或产品细节：无产品变更。和昨日 ChatGPT Pro 200 美元档停新订是两条线：一个是算力配额，一个是资本市场窗口
- 开发者可带走：不要把「2026 年 OpenAI IPO」写进预算或供应商风险表。真正要盯的是他有没有兑现与 Amodei 同款的嵌入评估员，以及内部「能力台阶上暂停」有没有对外可核验的触发条件
- 边界与风险：Fortune 标题容易读成「已改到 2027」；正文只否定 2026。双层治理能否在真正与股东利益冲突时按他说的运转，这篇访谈没有机制细节
- 为何重要：全球最被盯的一单科技 IPO 被当事人用安全理由从 2026 年日历上拿掉，和同一天的定速倡议互相背书

### 3. 新智元：Tibo 宣布 GPT-5.3-Codex-Spark 下周退役；Cerebras 上的「快」已从专用小模型变成旗舰档位
- 类型：工程
- 来源：微信公号「新智元」（网易号 2026-09-12 19:11）；对照 OpenAI 2 月发布稿、Cerebras 8 月 27 日 Ultrafast 博文、Tibo 9 月 11 日 X 帖
- 发布日期：宣布 2026-09-11；中文稿 9/12
- 链接：https://c.m.163.com/news/a/L6L9ED5F0511ABV6.html
- 阅读置信度：全文（新智元）；退役决定以 Tibo 帖为准。Terminal-Bench / SWE-Bench 分项、开发者评论来自该稿转述。上下文窗口该稿写 128k，OpenAI 2 月介绍页写 28k，以官网为准
- 一句话：OpenAI Codex 负责人 Tibo 称 GPT-5.3-Codex-Spark 下周退役，理由是用量持续下降、已有明显更好的模型，「该给未来腾地方」。它是 2 月 12 日上线的 Cerebras WSE-3 实时编程预览，官方速度是超过 1000 tokens/s。
- 中心思想：该稿的判断是：Spark 用「缩小版换速度」探路；8 月 13 日 Cerebras 把完整 GPT-5.6 Sol 切到多片 CS-3 流水线做成 Ultrafast（官方最高约 750 tokens/s，GDP-Val 样本端到端约 5.6 倍）之后，专用小模型没有位置了。「快」变成和推理强度类似的付费档位（Standard / Priority / Ultrafast）。
- 关键要点：
  - 官方发布口径（2 月）：ChatGPT Pro 的 Codex 应用 / CLI / VS Code 扩展研究预览；独立速率限制；API 仅设计合作伙伴。客户端–服务器往返开销降 80%、每 token 处理开销降 30%、首 token 延迟约减半——均为当时官方数字
  - 新智元转述的能力差距：Terminal-Bench 2.0 上 Spark 58.4%、完整 GPT-5.3-Codex 77.3%；SWE-Bench Pro 曲线上 Spark 把时长压到 1–2 分钟、准确率停在 47%–51%，完整版 3 分钟即 51%、9 分钟 56%、16 分钟 57%。发布次日有开发者指出官方「15 倍」是拿 Spark 对比开了最高推理强度的完整版，同等准确率下只快 1.37 倍——二手，待用原始帖核对
  - 该稿引用的开发者反应：有人把它当 Astra 主额度耗尽后的「不占主套餐备用油箱」；也有人抱怨 28k 级窗口做仓库理解和日志分析会迅速撑满。Hugging Face 的 Vaibhav Srivastav 在评论区道别。这些是社交转述，不是用量统计
  - 同系列清理：该稿列 6 月 2 日 GPT-5.2 与 GPT-5.3-Codex 退役、8 月 31 日 GPT-5.4 与 5.4 Mini 退役。Codex 命名改走 Sol / Terra / Luna / Astra
- 关键数据/指标：>1000 tokens/s、28k 上下文（官网）；Ultrafast 750 tokens/s、GDP-Val 样本 7.7 分钟→83 秒（Cerebras 8 月博文）。新智元写的 1200 tokens/s、128k、750 兆瓦/超 200 亿美元大单，需回源 Cerebras/OpenAI 合同口径，本稿不把合同总额当已核验事实
- 技术或产品细节：Spark 是 OpenAI 第一个在英伟达栈之外的生产模型，跑在 WSE-3。Ultrafast 把旗舰按层切到多台 CS-3，权重留在各片 SRAM，激活沿流水线走。速度档与推理档分开计费
- 开发者可带走：依赖 Spark 独立配额的工作流要在「下周」前迁到 Astra / Sol 的速度档。仓库级任务不要假设「更快的小模型」能补上下文；日志和多文件分析应直接用旗舰。Cerebras 路径还在，只是产品形态从「Spark 这一个模型」变成「旗舰的 Ultrafast 档」
- 边界与风险：退役具体时刻以产品界面和 API 名为准，该稿只写「下周」。Tibo 调侃「名字太长」不是技术评估。晶圆产能在 Spark 与 Ultrafast 之间如何切，OpenAI 没有公开配额表
- 为何重要：低延迟推理的产品单位从「专用蒸馏模型」改成「同一旗舰的硬件档位」，影响怎么写模型路由和账单

### 4. 量子位：生数 Motus2 把策略、预测、价值评估放进同一套权重，真机上用 MBRL 和规划把两项任务从 65% 拉到 75%
- 类型：工程
- 来源：微信公号「量子位」（2026-09-12 16:15）；对照新智元网易号（同日 15:20）、论文 arXiv:2608.30237、项目页
- 发布日期：外滩现场 9/10；公号与网易稿 9/12；论文 v2 修订 9/10
- 链接：https://www.qbitai.com/2026/09/487752.html
- 阅读置信度：全文（量子位 + 新智元）；84%、65%→75%、触觉 +12.5 个百分点、Ego 13 万小时均为论文/官方演示口径，无第三方复现。L3→L4 是生数自己的五级路线，不是外部认证
- 一句话：Motus2 用共享参数暴露三个接口：WAM 出动作、AC-WM 预测视觉后果、VM 打分。推理时 Best-of-N 规划，训练时只更新动作相关参数做基于模型的强化学习。量子位把它写成对 RSI 的「初步探索」，并写明这不等于开放环境里无限自学。
- 中心思想：现有世界模型常在模拟器上外挂动作头，动作会「偷看」未来帧。Motus2 在中后期训练改成 Action-first：先按当前观测出动作，再预测，再评估。失败轨迹用来学动力学和价值，不再当噪声丢掉。
- 关键要点：
  - 手机放置 + 多指操作：基础策略平均 65%；只加规划 67.5%；只加 MBRL 72.5%；两者一起 75%（+10 个百分点）。五项主要真机任务（放置小球、多指、贴合橡皮、拧灯泡、放置手机）平均 84%——新智元与量子位均引用
  - 触觉专家复用主模型中间结果，不每次重跑视频骨干。抽纸杯、撕纸：60%→72.5%（+12.5 个百分点）。记忆默认缓存近期真观测；找隐藏方块、按历史提示按按钮，保留完整历史平均 57.5%，高于压缩历史。量子位写这是阶段性妥协，不能据此说压缩路线走不通
  - 数据三步：单目 Ego 预训练 → 双目视频+人类动作 → 机器人轨迹和人机对齐。约 13 万小时人类第一视角 + 百小时级机器人/对齐数据。只做人类预训练：五项真机平均 51%；加上机器人中间训练：84%（+33 个百分点）。双目数据 2000→20000 小时，人类动作预测验证误差持续下降、未见明显平台
  - 真机平台包括单手 22 自由度 Sharpa Wave、20 自由度 WUJI Hand 2。朱军团队的 GWM 五级是：L1 生成世界、L2 交互、L3 在世界中行动、L4 自主世界智能体、L5 世界组织者。官方定位是 L3 已具备、用评价与反馈去碰 L4
- 关键数据/指标：上表均为论文/演示。无公开参数量、训练算力或 API
- 技术或产品细节：块内自回归掩码禁止未来视频进入动作预测；未来视频可读动作；价值查询可读两者。部署时可只跑 WAM，需要规划或 MBRL 时再打开预测和评估。项目：https://motus-robotics.github.io/motus2/
- 开发者可带走：若在做 VLA，先检查信息流是不是 Action-first，避免用未来帧反推当前动作。失败轨迹可以留给动力学和价值头。触觉不要另挂一套重模型挡在控制频率上。不要把 84% 读成家务通用
- 边界与风险：五项任务、特定灵巧手、实验室布置。触觉跨本体迁移、长时程预测、开放世界持续学习，量子位自己列为未解。RSI 在这里等于「用自身预测和价值信号改策略」，不是模型改自己的权重训练代码
- 为何重要：国内世界模型从「能预测下一帧并出动作」推进到「预测结果能反过来改策略」，和同日 Amodei 谈的实验室 RSI 不在同一层级，但共用同一个词

### 5. 澎湃：外滩具身 CEO 圆桌——先去工业物流康复干活，进家庭仍说不准三年还是五年
- 类型：产品 / 行业
- 来源：澎湃新闻（记者喻琰，2026-09-12 11:07）；新浪财经转载
- 发布日期：论坛 2026-09-11；稿件 9/12
- 链接：https://finance.sina.com.cn/jjxw/2026-09-12/doc-inirpute8479369.shtml
- 阅读置信度：全文（澎湃现场）；千万小时数据、「今年到后年规模化」是嘉宾个人判断，不是行业统计
- 一句话：9 月 11 日「具身 CEO 产业论坛」上，傅利叶顾捷、蚂蚁灵波朱兴、乐聚常琳、大晓/商汤王晓刚、地瓜王丛、青心意创牛腾昦对「机器人进家庭」一致谨慎。共识是未来一两年增速最快的是工业、物流、康复这类封闭、短链条场景。
- 中心思想：台上的人比观众更急着让机器人「去干活」，但干活不等于进家门。朱兴用「童工」形容当前智能，理由是不进真实场景就没有持续进化的数据；顾捷说医院客户看疗效、安全、稳定性和回报，不看是模型还是传统编程。

- 阅读置信度：全文（官方）；「覆盖 AUTOMATIC1111 大部分功能」是作者声明。Space 上的模型调用走登录用户自己的 Inference Providers 配额
- 一句话：AUTOMATIC1111 的 txt2img、hires fix、img2img、prompt matrix、Interrogate、检测转 inpaint 掩码、ControlNet 式 annotator、去背、PNG Info、图生视频，被收进一张 `gr.Workflow` 画布。11 条流水线、73 个节点；每个输出节点自动变成 API，不必手写路由。
- 中心思想：节点只有四种算子：`fn`（Python 函数）、`model`（Inference Providers）、`space`（另一个 Space）、`dataset`（Hub 行）。同一张画布能混扩散、LLM、VLM、检测器和视频模型；没有 GPU 也能跑，因为重活在别人的硬件上。
- 关键要点：

  - 结构：36 个算子节点里 32 个是 `fn`，其中 22 个完全本地、不访问网络；断网时大约三分之二画布仍可用。CPU annotator（Canny、线稿、sketch、luma-depth、posterize）在预载样张上各约 0.5 秒
  - 例子：hires / img2img 走 FLUX.1-Kontext；prompt 扩写走 Qwen3-4B；反推 prompt 走 Qwen2.5-VL，可与 ViT 分类并行；检测用 DETR，画框和掩码在本地 Pillow/NumPy 做。prompt matrix 没有循环算子，四个文生图节点同深度并行。放大：本地 Lanczos `fn` 或 AuraSR Space；去背：BRIA RMBG-2.0 Space。图生视频：Wan 2.2 I2V A14B，与 PNG Info 共用同一张图，不用二次上传
  - 本地 GPU：`fn` 里 `@spaces.GPU` 即可，示例 FastVideo/fastvideo-fasth3-preview。作者拿它和 ComfyUI 比：节点可以是你不拥有的硬件；输出自带类型化 REST；OAuth 后别人打开即用
- 关键数据/指标：73 节点 / 11 流水线 / 9 端点。无延迟 SLA、无与 AUTOMATIC1111 的逐功能对照表
- 技术或产品细节：Space `ysharma/Workflow1111`，可 Duplicate 后改边。最小代码是 `gr.Workflow(bind=[your_function]).launch()`。AUTOMATIC1111 原仓库仍是 AGPL-3.0；Gradio 是 Apache-2.0，该 Space 作者写 MIT
- 开发者可带走：要把扩散流水线给 Agent 调，先 Duplicate 再 `mcp_server=True`，不要在 AUTOMATIC1111 外包一层 Selenium。配额在调用方 HF token 上，共享 Space 不会攒到别人的密钥。需要本地权重时把 `model` 节点换成加载 checkpoint 的 `fn`
- 边界与风险：没有 loop 算子，批量要靠并排节点，画布会变宽。依赖 Hub Inference Providers 的节点受服务和配额限制。这是功能复刻演示，不是 AUTOMATIC1111 插件生态的迁移工具
- 为何重要：把「浏览器里的节点图」和「Agent 可调用的 MCP 工具」收成同一份图，生成式工作流的接口从 UI 自动化变成画布自带 API

## 给开发者的思路
1. Harness 这周要选形态，而不是再追一个模型名。OpenAI 把 Codex 循环收成托管 API（按 token/工具计，沙盒另算）；DeepSeek 继续插件化；英伟达 SoL-Pi 在 Pi 上证明：删掉「编辑完再问一次模型」、把大段输出换成句柄，token 可以少一半左右，但 Terminal-Bench 4 上少解了 3 题，20 个原版 Pi worker 的那次试验也没有打过单 Sol。先对自己的轨迹做一次计数：有多少轮是编辑后立刻跑测试、有多少上下文是整文件重放，再决定装 SoL-Pi、改用 Agents API，还是继续自建。
2. 「快」不再是一个模型。Spark 下周退役，独立配额会消失；Cerebras 路径还在，但是 GPT-5.6 Sol Ultrafast 这种旗舰档。GitHub Copilot 审查则开始在防火墙后跑构建和测试，Lite 也改成多 Agent。把路由表改成「模型 × 速度档 × 是否允许出壳」，不要再写死 `gpt-5.3-codex-spark`。
3. 具身和安全是两套 RSI，别混着用词。Motus2 的 RSI 是用自身预测和价值信号改动作策略，真机数字绑在特定任务和灵巧手上；Amodei 的 RSI 是模型参与造下一代模型，对策是嵌入评估员和（他希望的）行业定速。外滩 CEO 把进家庭从近路里拿掉。若既买实验室世界模型又买前沿 API，合同里分开写：真机成功率的场景边界，以及供应商是否允许第三方看到训练管线——Altman 否定 2026 IPO 并没有给出后一项的时间表。
