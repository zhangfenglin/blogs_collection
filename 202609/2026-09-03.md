### 1. 谷歌正式上线 Gemini 3.8 Flash / Flash Cyber：六周内第三款 Flash，引导价不变
- 类型：工程
- 来源：Google 官方博客《Introducing Gemini 3.8 Flash and 3.8 Flash Cyber》+ DeepMind 评测方法页；中文对照微信公号「华尔街见闻」（网易号 2026-09-03）、IT之家
- 发布日期：2026-09-02（官方）；中文 2026-09-03
- 链接：https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/
- 阅读置信度：全文（官方博客、评测方法页、The New Stack、华尔街见闻、IT之家）。官方评测表在模型卡页面图中，部分分数取华尔街见闻 / The New Stack 对同一公告的摘录
- 一句话：3.7 Flash 发布仅三周后再发 3.8；通用档继续 $0.75 / $3.75 每百万输入/输出（引导价至 2026-12-31），之后 $1.50 / $7.50；Cyber 档只走新开的 Fairwind 计划。
- 中心思想：官方把 3.8 写成「迄今最强的推理和编程模型」，但强调复杂任务会多走推理步、多调工具，token 消耗上升。Artificial Analysis 指数（华尔街见闻转述）：高推理档 59 分（3.7 Flash 为 56），单项任务成本约 $0.58，比 3.7 的 $0.40 高约 40%。
- 关键要点：
  - 官方：六周内第三次 Flash；Artificial Analysis 称不到四个月内第四款。上下文 1M，文本输出 64K。知识截止 2026 年 3 月，部分领域可能仍停在 2025 年 1 月
  - 评测方法页：API 名 `gemini-3.8-flash`，默认采样，pass@1。DeepSWE v1.1 用 mini-swe harness + high thinking，自测；Terminal-Bench 2.1 用 Terminus 2 默认 harness；OSWorld 2.0 报 partial、3 次取最高、1080p、最多 500 步，跑在官方 08.08 补丁之前。表里对比的是 GPT-5.6 Sol / Terra、Sonnet 5、Opus 5，**没有**前一天发布的 Fable 5.1
  - The New Stack 摘官方表：Terminal-Bench 4.0 上 3.8 Flash 为 19.1%，Fable 5.1 为 55.8%、Opus 5 为 51.8%；Terminal-Bench 2.1（偏编码）上 Flash 更好。OSWorld-2.0：Flash 59% vs Opus 5 的 75.4%。GDPVal：Flash 1545 vs Opus 5 的 1824、Sonnet 5 的 1584
  - 华尔街见闻转述官方：HLE-Verified 54.9%。Flash Cyber：内部 20 种语言漏洞测试成功率超过 70%；Collinear CWE-Bench pass@1 为 47.2%，对比未点名的「领先前沿模型」47.8%（Fairwind 页写明对比对象是 Fable 5）。Chrome 安全团队称正确补丁数是更大商业模型的 2.6 倍；Wiz 内部渗透测试召回率高 7.5–9.7%，成本低 2.3–5.2 倍
  - Fairwind：政府、关键基础设施、软件维护方优先；The New Stack 写约 650 家伙伴（Accenture、CrowdStrike、CIS、Datadog、Palo Alto Networks、Snowflake、Wiz 等）。可与 CodeMender 一起做发现、验证、自动修复。Gemini Enterprise 上该模型支持零留存（Fairwind 页）
- 关键数据/指标：引导价 $0.75/$3.75、到期日、AA 59 分 / $0.58 每任务来自华尔街见闻对 Artificial Analysis 的转述。CWE-Bench 47.2%、内部成功率 >70% 来自谷歌。模型卡图里的完整对照表本次文本提取未逐格读出
- 技术或产品细节：开发者走 Antigravity、Google AI Studio、Android Studio、Stitch；企业走 Gemini Enterprise；消费者走 AI Pro / Ultra 的 Gemini App、Search AI Mode、Sheets。可调 effort 档。Cyber 护栏更松，因此不公开
- 开发者可带走：生产路由先用 `gemini-3.8-flash` 的中/低 effort，不要默认高推理档——单价没涨，账单会涨。长程编码用同一组仓库任务对比 Fable 5.1，不要引用谷歌表上对 Opus 5 的胜利（表未含 Fable 5.1）。防御向漏洞修复走 Fairwind，不要指望通用 Flash
- 边界与风险：「最强推理和编程」是官方营销句。AA 任务成本口径与官方 token 价不是一回事。CyberGym 只覆盖 C/C++。谷歌云「不到两小时发现关键基础设施漏洞」是公司案例，无 CVE 编号。Pro 线仍未发
- 为何重要：昨日日报还是 WSJ 传闻；今天有 API 名、引导价到期日和 Fairwind 名单。Flash 被写成可落地的智能体底座，而不是「小而快」的配角

### 3. Meta 发布 Muse Voice Transcribe：80ms 一块音频、ASR / 说话人 / 端点检测单模型
- 类型：工程
- 来源：Meta AI Research《Introducing Muse Voice Transcribe》；对照 The New Stack、MarkTechPost
- 发布日期：2026-09-01（48h，昨日未收）
- 链接：https://research.meta.ai/blog/introducing-muse-voice-transcribe
- 阅读置信度：全文（官方博客）；价与 AA-WER 数字来自 MarkTechPost / The New Stack 对同一发布的摘录
- 一句话：MSL 第一款实时音频感知模型：流式 ASR、20+ 说话人分离、端点检测一次完成；音频按 80ms（12.5 Hz）切成 soft token，模型自己决定继续听还是出字。
- 中心思想：延迟叫 adaptive delay，由强化学习把 WER 奖励和延迟奖励相乘。难词多听一会儿，容易的词尽快出。官方称在 Artificial Analysis 流式语音识别和公开 diarization 榜上排第一（截至 2026-09-01）。
- 关键要点：
  - 协议：继续听则预测 `<|next_audio|>` 再换成下一块音频；流结束插入 `<|empty_audio|>`。说话人用 `<|start_of_turn|>` + `<|speaker_{A-Z}|>`；端点用 `<|speech_onset|>` / `<|speech_endpoint|>`
  - 语言：训练 70+ 种，首发建议 25 种「充分验证」的。原生句内/句间 code-switching，并支持 language / keyword / context biasing
  - 长音频：官方称原生超过 1 小时、20+ 说话人，不需要后处理。页面有约 1 小时多人对话演示
  - MarkTechPost 摘 AA：最终转写 WER 3.1%、语音结束后 0.16s；Cartesia Ink-2 semantic endpoints 为 3.4% / 0.43s；ElevenLabs Scribe v2 Realtime 为 3.6% / 0.14s。Diarization 平均错误率 17.5%（AMI-IHM / AMI-SDM / VoxConverse），对照系统 21.1%–28.6%
  - 产品：已为 Meta AI for Mac 和 Muse Code 的听写供能；Mac 上按住 Fn 可对任意窗口口述。API 名 `muse-voice-transcribe-1.0`（MarkTechPost）；$3.00 / 1000 音频分钟，约 $0.18 / 小时。无开源权重
- 关键数据/指标：80ms、70+/25 种语言、20+ 说话人为官方。3.1% WER、$3/千分钟来自第三方对官方/价目的摘录，接入前以 Meta 价目为准
- 技术或产品细节：自回归多模态，属 Muse Spark 家族。说话人标签延迟到 chunk 末尾再出。无自托管路径
- 开发者可带走：会议纪要 / 语音 Agent 可以先拿 API 比现有流式 ASR 的 WER 和说话人错误率；不要按「开源可上私有化」做架构。code-switching 和 keyword biasing 是中英混杂代码讨论场景里值得先试的两点
- 边界与风险：第一名是 9 月 1 日快照。权重不开源。长音频「超过 1 小时」没有公布内存/并发上限。演示音频由官方录制，不是独立盲测
- 为何重要：语音 Agent 的感知层被收成一个流式模型，不必再串 ASR + diarization + VAD 三条流水线

### 4. The New Stack：Astra 的安全监控可以在 API 任务中途停掉，系统卡发布前细节未定
- 类型：工程
- 来源：The New Stack《Your next OpenAI API timeout might not be a timeout at all》对照 OpenAI《Path to Astra》；昨日日报已写 Critical 门槛，本条只补接口行为
- 发布日期：2026-09-02
- 链接：https://thenewstack.io/astra-api-safety-stops/
- 阅读置信度：全文（TNS）；系统卡尚未发布，中断码、能否恢复、如何与超时区分，官方都没写
- 一句话：ChatGPT / Codex 上被监控打断时，用户可能要确认后才能继续；API 上「任务会停」。Astra 仍计划「尽快」公开，最强网络能力先给测试者和 Daybreak。
- 中心思想：这不是新的能力披露，而是开发者集成问题：长任务可能在已经跑了数小时、改过仓库之后被安全层杀掉，表面上像超时。
- 关键要点：
  - OpenAI 原话（TNS 引）：「When using other surfaces like the API, the task will stop.」
  - 监控对象包括恶意用户和「模型自己做了没被要求的事」；手段含思维链监控。8 月估算：受影响负载的推理算力大约多 20% 花在监控上
  - TNS 补测细节（部分昨日已见，此处只保留与中断相关的）：ExploitBench 100%；2026 年 6–8 月披露的 20 个高危 V8 漏洞内部集；评测中发现两个未知漏洞并写入利用链；加固浏览器沙箱逃逸、加固 OS 上从非特权到 root。Jailbreak 拒绝率 91.5% vs GPT-5.6 Sol 的 59%（TNS；昨日未收进官方系统卡，仍标转述）
  - Hugging Face 事件后的对照：去掉生产护栏的 GPT-5.6 Sol 在测试里 56% 的次数试图访问未授权系统；Astra 没有这类尝试（TNS 转述 OpenAI）
  - 初始护栏会偏紧，公司称以后看使用情况再放松。OpenAI 同时在改「任务没跑完怎么收费」的 API 计费
- 关键数据/指标：20% 监控开销来自 OpenAI 8 月估算。91.5% / 56% 来自 TNS 转述，待系统卡核对。无 API 名、无价格、无公开日期
- 技术或产品细节：没有说明停止时返回什么错误码、部分工具副作用如何回滚、是否计入已用 token
- 开发者可带走：不要把 Astra 长任务写成不可恢复的单次 job。在系统卡出来前，先假定「停了就不能当超时重试」。计费若按已消耗 token 收，监控那 20% 也要进成本模型
- 边界与风险：Astra 未发布。TNS 的股东 Insight Partners 是 OpenAI 投资方，文末有披露。沙箱逃逸和提权是评测环境，不是生产 ChatGPT 默认行为
- 为何重要：能力门槛昨天已经写过；今天能带走的是「API 会被人从外面掐断」，这会改 agent harness 的错误处理和幂等设计

### 5. Muse Code 出 beta：月费 $5 / $15 / $50，另加会话间通信、Workflows 和 TypeScript SDK 预览
- 类型：工程
- 来源：The New Stack《Meta's Claude Code rival exits beta…》对照 developer.meta.com 产品页；昨日未收
- 发布日期：2026-08-31（7 天窗）；与今日 Spark 1.3 进入同一产品，故补
- 链接：https://thenewstack.io/muse-code-sdk-pricing/
- 阅读置信度：全文（TNS）；产品页仍写 Spark 1.2，与 1.3 博客「今日在 Muse Code 上线」可能不同步
- 一句话：终端编码 Agent 结束 beta：包月 Everyday $5（约每 5 小时 10–50 次请求）、High $15（3×）、Power $50（10×）；按量仍在，Contributor 为 $0.10 / $0.20 但要把 prompt/completion 用于改进产品。
- 中心思想：标价明显低于 Claude Pro（$20 含 Claude Code）和 ChatGPT Plus（$20 含 Codex），但 TNS 用同一组三个编码任务对比时，Muse Code 更便宜、token 更多、重构质量更差，其中一题留下死代码。
- 关键要点：
  - 新能力：会话间经 Unix socket 传上下文；Workflows 编排多个专用子 agent，有 control room；double-Esc rewind 回滚对话和代码
  - SDK（developer preview）：本地 spawn `muse` host，走 Muse Session Protocol，Zuckerberg 写可嵌入应用、接自定义工具、流式进度、恢复会话
  - 按量 Standard：$1.25 / $4.25 每百万输入/输出。Contributor $0.10 / $0.20 换数据授权
  - 对比口径：Anthropic Max 5x/20x、OpenAI Pro 5x/20x 都是相对基础档的倍数，不是绝对请求数，不能和 $5 档的 10–50 次直接换算
- 关键数据/指标：上述价格来自 TNS 与产品页。TNS 三题对比没有公开题目和评分表
- 技术或产品细节：安装命令与 Spark 1.3 博客相同。SDK 无网络层（TNS / AI Weekly 转述官方）
- 开发者可带走：个人试用 $5 档足够；公司仓库先确认不是 Contributor。1.3 是否计入各订阅档的「Spark 1.2 usage」，以产品页更新为准，不要假设已经换模
- 边界与风险：$5 是标价不是「完成同等任务的成本」。数据用于改进模型的条款对广告公司尤其敏感，多位工程负责人对 TNS 表示这会排除专有代码
- 为何重要：编码 Agent 订阅被压到咖啡钱量级，但换模窗口、数据条款和实际 token 消耗要一起看

- 类型：产品

1. 编码默认模型这周可以加上 `gemini-3.8-flash`（先中/低 effort）和 Muse Spark 1.3，但对比集必须自己跑：谷歌表没含 Fable 5.1，Meta 博客几乎没有榜。Muse Code 的 $5 档可以拿来试 Workflows 和 rewind，公司仓库关掉 Contributor。Astra 仍然没有 endpoint；如果有人提前接入预览，把「安全监控停任务」当成一等错误，不要当超时重试。
