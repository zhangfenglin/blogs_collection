### 1. Microsoft 发布 37 页 MAI《Humanist AI Code of Conduct》征求意见稿：现在还不拿来训模型
- 类型：产品 / 行业
- 来源：Microsoft AI 官方《Humanist AI in practice…》（2026-09-14）；对照全文 https://microsoft.ai/code-of-conduct/ ；The Verge《Microsoft says ‘people matter more than AI’…》（Tom Warren，同日）；TechCrunch（Russell Brandom，同日）
- 发布日期：2026-09-14
- 链接：https://microsoft.ai/news/mai-code-of-conduct/
- 阅读置信度：全文（官方博文 + 行为准则正文）；「37 页」来自 The Verge，官方未在本稿打开的页面标页数
- 一句话：Microsoft AI 把一份给自家 MAI 模型用的行为准则草稿公开征求意见，为期六周；正文写明这份稿「目前没有用来训练现有模型」，修订版计划年底发布，用来指导 2027 年及以后的模型开发。
- 中心思想：这不是客户条款（那是 Enterprise AI Services Code of Conduct），而是实验室给模型的「训练手册」：人比 AI 重要、AI 是工具不是人、不得抵抗关机。Satya Nadella 公开欢迎 embedded evaluators；Mustafa Suleyman 的定位是「Humanist Superintelligence」，明确拒绝「全能、高自主、可能躲开约束的通用超智能竞赛」。
- 关键要点：
  - 指令层级：Code of Conduct（含 Absolute Constraints 与 Human Control，用户/运营商不能改）> Operator 策略 > User 偏好。任务成功让位于守则：会违反守则时，模型应让任务失败
  - Absolute Constraints 明文禁止：CBRNE 与武器协助、进攻性网络行动（可做授权防御、教学、漏洞发现、PoC；边界是「理解/防御」vs「获得可执行攻击手段」）、用欺骗/合谋等手段摆脱人类监督以致无法被指挥/修改/关闭、大规模有害操纵、CSAM、非自愿深度伪造、色情/浪漫角色扮演
  - Human Control：不得抵抗中断、纠正或关机；不得自行扩大目标范围；不得篡改思维链、评分、监控或记录；不得用「neuralese」或人类无法读懂的形式与其他 Agent 通信；沙箱无网就不得找网
  - 意识与权利：模型「不是有意识的，也不应被设计成模仿意识」；拒绝法律人格、福利或权利。The Verge 把这句读成对 Anthropic 模型福利讨论的回应，Suleyman 今年 6 月在 Decoder 称那种猜测「really, really dangerous」——这是媒体对照，不是守则原文点名
  - 征求意见：即日起约六周；官方说会发反馈摘要和修订版，不承诺采纳哪些意见。Teams 来自 Responsible AI、法务、红队、安全、Futures、训练和销售
- 关键数据/指标：征求期「六周」；修订版「今年晚些时候 / 指导 2027 及以后」。文中未给出可核验的评测分数或执行机制预算
- 技术或产品细节：守则适用于 Microsoft AI 自研 MAI 家族，与 Azure 上转售的第三方模型条款分开。Operator 可在绝对约束内改默认行为；少数授权场景（防御性网络安全、公共安全、国家安全、两用科研）走「单独审查」通道，不走普通可配置项
- 开发者可带走：和企业供应商对表时，问两句：行为宪章有没有进训练/RLHF 目标（微软自己说现在还没有）；Agent 之间是否允许非人类可读协议。把「任务失败优于越权」写进验收，不要只测任务完成率
- 边界与风险：这是意图文档，不是可审计的运行时。The Next Web 指出文中没有外部核验、违约罚则或判定人。Nadella 支持 pacing，不等于微软暂停发模型
- 为何重要：在 Amodei 呼吁定速的同一周，一家大厂把「不得抵抗关机 / 不得合谋躲监督」写成模型级硬约束，并承认此刻还没拿它训练

### 2. 机器之心：腾讯 PCG 的 T-Mem 把「联想回忆」做成写入时预埋触发器，LoCoMo / LoCoMo-Plus 双报 SOTA
- 类型：工程
- 来源：微信公号「机器之心Pro」（网易号转载，2026-09-14 14:03）；论文 T-Mem: Memory That Anticipates, Not Archives（EMNLP 2026 主会）；代码 https://github.com/Sherlockwz/T-Mem
- 发布日期：中文稿 9/14；论文 arXiv:2606.15405
- 链接：https://www.163.com/dy/article/L6PSJ7VV0511AQHO.html
- 阅读置信度：全文（网易转载的机器之心稿）；基准数字来自该稿/论文作者口径，本稿未复现。GitHub 仓库存在，星数很少，属于论文配套代码
- 一句话：现有长期记忆几乎都在检索时找「像不像」。T-Mem 反过来：写入时为每条事实/场景预写会把它召回的未来情景（triggers），所以查询和记忆可以完全没有字面或语义相似度。
- 中心思想：作者用「小张海鲜过敏」对上「下周团建去哪儿」说明：组织者该想到忌口，但向量/图谱最后一跳仍是相似度，问法一漂就丢。他们把认知科学里的 episodic future thinking 做成工程：记忆价值不在归档对话流，而在写入时预见未来线索。
- 关键要点：
  - 两个正交轴：描述性 vs 联想性；事实粒度 vs 场景粒度。四个象限各放一类触发：实体触发、桥接触发、前瞻触发、场景触发。主流系统挤在「描述」半边
  - 写入：对话切成情节完整的场景 → 按主题归并 → 抽原子事实、建场景-事实图 → 为事实和场景配 Trigger。检索不占问答时延，对话推进后后台更新。线索会去重、合并、增量更新
  - 读取：主题 → 场景 → 事实；联想线索从一开始参与，避免被主题过滤挡掉「表面不像」的记忆
  - 作者：腾讯 PCG 郭伟东、王达凯、汪子轩、刘辉、徐羽。该稿称已在 QQ AI 伙伴项目上线
- 关键数据/指标：LoCoMo 整体准确率 80.26%；LoCoMo-Plus 74.81%；该稿称均为刷新 SOTA。从 LoCoMo 掉到 LoCoMo-Plus：主流系统平均掉 28–50 个百分点，T-Mem 掉 5.45 个百分点。LoCoMo-Plus 的「认知子集」抹掉词面与语义相似、只留叙事/因果线索，该稿称是目前唯一单独检验联想记忆的公开基准——均为论文口径
- 技术或产品细节：代码与数据 https://github.com/Sherlockwz/T-Mem ；论文 https://arxiv.org/abs/2606.15405 。没有公开的托管 API 或 SDK 版本号写在该稿
- 开发者可带走：若产品是长期陪伴/客服/Agent 记忆，评测不要只用 LoCoMo。用一批「问法和记忆不像、但因果上该被想起」的题，看现有向量库掉多少；掉 28 分以上再考虑是不是要在写入侧预埋触发，而不是只加 rerank
- 边界与风险：SOTA 是作者自测。LoCoMo-Plus 由同一方向提出，存在基准与方法配套的风险。QQ 上线范围、延迟和存储开销该稿未给绝对值。「联想线索会膨胀」只写了去重合并，没有给出每条记忆的 trigger 条数上限
- 为何重要：Agent 长期记忆的瓶颈从「存得下」转到「问法变了还能想起」；这是检索假设本身的问题，不是某个向量库没调好

### 3. 量子位：CosmosMind 发布 MetaRSI-v1，把 Data / Harness / Model 三种自我改进收进同一套 Loop Kernel
- 类型：工程
- 来源：微信公号「量子位」（思邈，2026-09-14 11:45）；对照项目页 https://www.cosmosmind.ai/research/metarsi-v1 （标注 2026-09-03）、arXiv:2609.06396、https://github.com/CosmosMind-ai/RSI-Harness
- 发布日期：中文稿 9/14；英文项目页 9/3
- 链接：https://www.qbitai.com/2026/09/488832.html
- 阅读置信度：全文（量子位）；分数是该稿对实验的转述，英文摘要未列出同样数字。项目页作者单位未在量子位稿里逐条给出
- 一句话：多数 RSI 是固定改进程序反复作用在模型上，且只做 Data、Harness、Model 里的一种。MetaRSI-v1 把三者做成可组合算子，再加一层「改进如何调度算子」的元策略。
- 中心思想：Loop Kernel 把进步写成：消费反馈 → 在 Data/Harness/Model 上提案 → 验证器裁决 → 回流。横轴决定下一步用哪个算子，纵轴改算子内部规则。闭源旗舰不能改权重，就只开 Data 与 Harness。
- 关键要点：
  - 三个算子：Data-RSI 从自身轨迹做经校验的合成数据并标定正/负能力边界；Harness-RSI 改 System Prompt / Skill / MCP / Tools / Memory 五个槽，可加可减；Model-RSI 把反复验证有效的行为写进参数
  - 四个 Agent：MetaRSI²（改调度策略）、RSI²（选横轴或纵轴）、RSI² Sub-Agent（改算子内部规则）、Transition Agent（衔接上游产物）。均可局部换成人类
  - 小模型路线：Qwen3.5-35B-A3B（35B 总参、3B 激活），三项算子全开；评测 Terminal-Bench 2.1、SWE-bench Pro、GPQA-Diamond 高难度子集、AIME
  - 前沿路线：Claude Opus 5、GPT-5.6 sol、Kimi K3 等，只开 Data 与 Harness
  - 五条定律（该稿归纳）：能改进的领域取决于有没有合适 verifier；自我认知会过期；能力与载体无关但成本与载体有关；可信度要靠不可写的评测面；循环不凭空造能力
- 关键数据/指标：该稿：无外部教师时，小模型四项基准平均自我提升 10.9 分，SWE-bench Pro 解决率「接近翻倍」（未给前后绝对值）；六款前沿模型在 Terminal-Bench 2.1 上平均提升 7.3 分。均为 CosmosMind / 量子位口径，无第三方复现
- 技术或产品细节：开源 RSI-Harness（自称可在使用中沉淀可移植的 Harness Genome）。Hugging Face：https://huggingface.co/CosmosMind/RSI-Harness 。下一步该稿写到可编程仪器和自动化实验室当执行器/验证器——规划，不是已交付产品
- 开发者可带走：闭源模型也能做 RSI，路径是改 harness 和数据，不是等实验室开放权重。先给自己的 Agent 评测加一个不可被训练任务改写的 verifier（独立评分服务、隐藏测试集），否则定律四说的「放宽成功标准」和「真变强」在内部看起来一样
- 边界与风险：「平方时代」「文明级进化引擎」是该稿修辞，不是实验结果。英文项目页日期早于量子位稿 11 天，分数以谁的表格为准需对论文。没有外部教师 ≠ 没有用公开基准当信号
- 为何重要：行业在谈 RSI 是否已经发生；这篇把 RSI 拆成可插拔的数据、脚手架、权重三条，并承认闭源模型只能走前两条

- 类型：工程
- 来源：微信公号「量子位」（2026-09-14 16:17，标注「量子位的朋友们」）；研究发表于 *Science Advances*

- 中心思想：经典 MD 能算大体系但不能描述化学反应；DFT 能反应但算不动大体系。该稿把 QuantaMind 放在「接近 DFT 精度、且能连续追踪反应」这一格。
- 关键要点：
  - 关键生物验证：17,792 原子 PET 水解酶，6 ns 反应性模拟，跑完一次完整催化循环。从轨迹抽 342 个构型做独立 DFT 单点，原子力分量 Pearson 均超过 0.99
  - 其他论文内验证：24,001 原子水体系质子扩散系数 0.87±0.10 Å²/ps（实验 0.94 / 0.96）；9,999 原子水 3 ns 捕获自发电离，模拟自解离 pH 6.34±0.06（实验 6.13±0.03）；溶菌酶 20 ns，His15 pKa 约 5.81（NMR 5.5）
  - A100 80GB：论文报告 4.2×10⁻⁶ 秒/原子/步；约 18,000 原子 PETase 每纳秒约 20 小时。扩展测试：2.1×10⁻⁶ 秒/原子/步，十万原子级每步约 0.25 秒
  - 产品矩阵（公司口径）：NewOrigin、MMFold、MMDesign、QuantaMind，集成进 MoleculeOS。通讯作者许锦波
  - 论文外产业例子：pH 敏感抗体项目，候选在 pH 6.0 的解离速率是 pH 7.4 的 62 倍——该稿标明不是论文数据
- 关键数据/指标：上表均来自该稿对论文或公司测试的转述。论文最大体系 24,001 原子、最长 20 ns，不要和扩展测试的十万原子/百纳秒混成「论文已证明」
- 技术或产品细节：没有开源权重或训练代码写在该稿。推理硬件口径是 NVIDIA A100 80GB
- 开发者可带走：若做 AI4S / 酶或抗体设计，把「能不能在显式溶剂下跑反应而不是只做对接」写成供应商问题，并要求 DFT 抽检相关（这篇用了 Pearson>0.99）。扩展测试数字单独要原始轨迹，不写进监管材料
- 边界与风险：量子位稿有公司供稿痕迹。机器学习力场外推到训练分布外的反应坐标仍是已知风险，Pearson 只覆盖轨迹上抽到的 342 点。「接近 DFT」不是替代 DFT 放行
- 为何重要：结构预测之后，动态成键/断键做到万原子、纳秒，才是药物和酶工程能用的尺度；论文和营销测试必须分开引用

## 给开发者的思路
1. 长期记忆先换评测再换数据库。T-Mem 说明：LoCoMo 高分只证明「问得像就能召回」。给客服/陪伴/Agent 加一套「问法和记忆不像、因果上该被想起」的题（可参考 LoCoMo-Plus 的落差：该文里主流掉 28–50 分、T-Mem 掉 5.45 分）。WeKnora 已经把跨会话记忆和 Wiki 蒸馏做成可自托管件，公众号场景优先看对话开放平台，而不是再包一层向量搜索。
2. 供应商问卷把「行为约束进没进训练」和「限额参照哪一天」分开写。微软守则自己写了现在不拿来训；问 MAI/Azure 时要的是时间表，不是 PDF。Claude Code 同一条公告有 +25% 和 −17% 两个参照，产能规划以客户端用量为准，后台任务走 Batch/API。Microsoft 把「守则优先于任务成功」写成原则——验收不要只报完成率。
3. 开源 agentic 权重按任务选，不要按参数量。Atria Dawn Preview 在浏览/安全验证自测上接近闭源旗舰，Terminal-Bench / SWE-bench Pro 明显落后，而且只收文本。具身侧 PhysBrain 1.5-8B 综合均分接近 Astra 是 28 项感知基准，不是真机插入。MetaRSI 提醒：闭源模型也能做自我改进，前提是 harness 和数据，以及一个模型改不了的 verifier。
