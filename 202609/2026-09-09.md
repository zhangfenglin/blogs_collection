### 1. 面壁智能开源 MiniCPM5-2B：标准 Llama 架构、131k 上下文，官方对比表均分 53.9
- 类型：工程
- 来源：Hugging Face 模型卡 `openbmb/MiniCPM5-2B` / `MiniCPM5-2B-SFT` README-cn；对照光明网、上证报中国证券网（经济观察网转载）2026-09-08
- 发布日期：权重页写 9 月 7 日发布；中文媒体 9 月 8 日报道
- 链接：https://huggingface.co/openbmb/MiniCPM5-2B
- 阅读置信度：全文（模型卡）；媒体 AA 分数与官方对比表不是同一套口径
- 一句话：面壁智能联合 OpenBMB 开源 MiniCPM5-2B，定位端侧 / 本地 / 资源受限场景的 2B 稠密模型。官方对比表均分 53.9，高于同表里的 Qwen3.5-4B（51.1）。权重 Apache 2.0；同步开 UltraData 系列训练数据，以及 Base / Midtrain / SFT / RL+OPD 正式版等多档 checkpoint。
- 中心思想：这不是又一个聊天 2B。卖点写在工具调用、coding agent 和「标准 `LlamaForCausalLM`、无需自定义算子」。媒体另给了一套 Artificial Analysis 分数，和官方 53.9 表不要混写成同一榜。
- 关键要点：
  - 架构：42 层，总参 2,516,756,480，非嵌入 1,981,982,720；GQA 16 个 Q / 2 个 KV；词表 130,560（DataLearner 转模型卡）；原生上下文 131,072
  - 后训练：400B tokens deep-thinking SFT → 多领域 RL teacher → On-Policy Distillation（OPD）把 16 个专家（含 5 个 agentic）并回同一发布模型。官方：RL+OPD 在所列推理与通用基准平均 ↑10.96，Agent 平均 ↑6.96
  - 官方表摘录（带 † 的取自 Artificial Analysis，其余为内部复现）：LiveCodeBench v6 69.1；AIME 2025 / 2026 均为 86.5；SWE-bench Verified 46.4（同表 Qwen3.5-4B 为 33.6）；τ²-Bench Telecom 97.1；Terminal-Bench v2.1 8.6†（Qwen3.5-4B 为 25.8†，这一项 2B 并未打过 4B）
  - 上证报：Artificial Analysis 综合 23 分、4B 以下开源第一；Agentic Index 20 分，对照 Granite 4.2 8B 的 9 分、Qwen3.5 9B 的 7 分。光明网另写真实任务 891 分（人类基线 1000），Qwen3.5 9B 645、Gemma 4 12B 647。三套数字并存，引用时写来源
  - 截至 2026 年 8 月，MiniCPM 系列全球下载量公司称突破 5000 万次（光明网 / 上证报）
- 关键数据/指标：2,516,756,480；131,072；53.9 / 51.1；46.4 SWE-Verified；23 / 20 / 891 为媒体对 AA 或内部任务的转述
- 技术或产品细节：`vllm>=0.21`：`vllm serve openbmb/MiniCPM5-2B`。SGLang `>=0.5.16`，工具调用推荐 `--tool-call-parser minicpm5`（XML → OpenAI `tool_calls`）。投机解码草稿模型 `openbmb/MiniCPM5-2B-DSpark`。另有 GGUF / MLX / GPTQ / LiteRT。FlagOS 已出 Nvidia、海光、沐曦、天数、真武、摩尔线程、昆仑芯、昇腾、ARM-v9 九套 FlagRelease 权重。采样推荐 `temperature=1.0, top_p=0.95`
- 开发者可带走：端侧先下 GGUF / MLX，不要按 BF16 估手机。工具调用走 SGLang parser，不要自己拆 XML。SWE-Verified 46.4 值得在自有仓库复测；Terminal-Bench 上 4B 仍明显更强，别把「2B 全面超过 4B」写进选型材料
- 边界与风险：53.9 是官方自选对照集的均分，不是 AA 总榜。媒体 23 分与 891 分口径未在模型卡展开。公司称「端侧通用 Agent 雏形」，真机时延、电量和工具成功率本文没有
- 为何重要：2B 档第一次把 SWE-Verified 拉到 40+ 并公开完整数据与多芯镜像；本地 Agent 的默认对照从 Qwen3.5-2B 换成这一档

### 2. 量子位：王云鹤团队发布 NeoHorse-1，4B 后训练宏平均 58.94→64.87
- 类型：工程
- 来源：微信公号量子位《王云鹤创业后交出首个模型》（衡宇，2026-09-08）；对照雷峰网同日对技术报告的摘录
- 发布日期：2026-09-08
- 链接：https://www.qbitai.com/2026/09/485555.html
- 阅读置信度：全文（量子位）；分数来自该公司技术报告，雷峰网写 11 项基准、量子位写 10 项，引用时分开
- 一句话：华为诺亚前主任王云鹤创办的基元律动（TokenRhythm）发布 Agent-Native 模型 NeoHorse-1，4B / 9B 两个尺寸，底座分别是 Qwen3.5-4B 和 Qwen3.5-9B。训练语料核心是 Routing Harness（开源项目 OpenSquilla）里的多模型执行轨迹，而不是只学问答对。量子位：4B 经 Agentic Post-Training 后宏平均 58.94→64.87，达到同规模 SOTA，并在全部可对比基准上超过 Qwen3.5-4B。
- 中心思想：公司没有改口去做「又一个基础模型」。它把调度层攒下的失败、升级、接手路径写进权重，用来补 4B 在流程清晰、反馈可观察、结果可验证任务上的缺口。
- 关键要点：
  - 轨迹里除了问答，还有：路由器对能力档的判断、选了哪个模型、工具调用、环境返回、何时升级到更强模型、额外花了多少 Token 和时间
  - 筛选：结构检查（请求 / 回复 / 工具 / 环境能否对应）+ 六个质量维（目标是否完成、是否遵守指令、工具是否合理、结论有无证据、出错能否恢复、该不该终止）。「流程走完」和「用户目标满足」分开记
  - 训练：Routing-Guided Curriculum（按路由估计的能力档由易到难）+ On-Policy Distillation（教师对着学生实际走到的步骤给指导）
  - 排期例子：基座找到工作目录文件，却漏读含最新依赖约束的邮件，按过期信息排期并写错位置；后训练版会继续读新证据、重算、验证、存到正确位置
  - 雷峰网：所列 4B 级里 NeoHorse 4B 未加权平均最高，并在五项基准上超过 Qwen3.5-9B 底座。复杂状态维护、长程调试、失败恢复仍是更大模型的优势
  - 量子位把 RSI 拆成 Data-RSI 与 Model-RSI，并写明目前只验证了单轮「执行—评估—选择—更新」，信号和奖励仍由人设定
- 关键数据/指标：58.94→64.87（量子位转技术报告宏平均）。无公开 SWE-Bench 分、无 API 价
- 技术或产品细节：GitHub `TokenRhythm/NeoHorse`；HF collection `TokenRhythm/neohorse-1`。产品线另有开源 Routing Harness OpenSquilla，以及自称「中国版 OpenRouter」的 TokenRhythm API。算力与 Infra：无问芯穹；算法：清华、北大；雷峰网还写阿里巴巴参与开源生态协作
- 开发者可带走：有多模型路由日志的团队，可以把「失败后谁接手、环境如何验」当成后训练信号，而不是只蒸馏最终答案。4B 适合流程清楚的工具任务；长程调试别指望这一档替换 9B
- 边界与风险：10 项 vs 11 项评测数两稿不一致。SOTA 是报告自列对照。完整 RSI 未证明。上游模型厂自己做 Harness 会压缩中间层空间——量子位原文已写这一点

### 3. Mostik 用「桥」传隐藏状态：753B GLM-5.2 只做预填充，4B Qwen-3.5 写答案
- 类型：工程
- 来源：微信公号量子位（衡宇，2026-09-07，凤凰网大风号转载）；对照 WIRED、ForkLog
- 发布日期：量子位 2026-09-07；ForkLog 英文稿 2026-09-04
- 链接：https://tech.ifeng.com/c/8wECyJxesUg
- 阅读置信度：摘要级（技术细节因 ARC-AGI 3 比赛未结束未公开；演示数字为团队自述）
- 一句话：成立约 4 个月、15 人（12 名博士）的 Mostik（俄语「小桥」）训练一座小型桥，把发送方模型的隐藏状态转成接收方可直接用的表征。公开演示：智谱 GLM-5.2（753B）只读题、不生成任何 token；阿里 Qwen-3.5（4B，可在手机跑）负责全部解码。双方权重冻结，只训桥。团队称可补上约 50% 的大小模型性能差距，4B 自身准确率 +25%，难题子集约 2 倍；大模型侧推理成本约压到原来的 1/20。
- 中心思想：多模型协作今天走的是文本（量子位写：生成一个 token 时内部约两兆字节状态，输出约 17 bit）。桥想跳过这层压缩。ARC-AGI 3 上的参赛配置与 753B+4B 演示不是同一套，不要写成「手机 4B 单机打满 ARC」。
- 关键要点：
  - 成本结构：预填充便宜、逐 token 解码贵。大模型只做预填充，解码全给小模型
  - 相对「中等规模模型跑出同样成绩」，桥方案算力约为其 2/5（量子位）；ForkLog 写约 2.5 倍更省。口径略有出入，都是团队估算
  - 优势在「交接点极早」时最大：大模型还没写出字，隐藏状态里已经有处理过程
  - 首席科学家 Stanislav Smirnov（2010 年菲尔兹奖，日内瓦大学）：「目前似乎还没有合适的数学语言」描述表征如何对应。CEO Sasha Malysheva 是方法开发者之一
  - 下一步（团队表述，早期）：把内部状态用于蒸馏；给小模型加专项技能同时保留通用能力；把桥当观察面（发送状态 / 转换结果 / 接收行为）
  - ForkLog：ARC-AGI-3 榜上有 preview 条目，可能基于不完整测试集，不能当成最终外部验证
- 关键数据/指标：50% 差距、+25%、2 倍、约 1/20、2/5。均为 Mostik 自述。竞赛具体模型与 harness 未披露
- 技术或产品细节：无开源权重、无 API。此方法需要隐藏状态，闭源云 API（Claude / GPT）接不上。Google DeepMind 工程师 Susan Zhang 对「能控制内部状态却冻结权重」提出过质疑（KuCoin 快讯转述，待核实原文）
- 开发者可带走：自有开权重大小模型对，可以先当研究原型：大模型 prefilling → 小模型 decode。生产上别接闭源 API。ARC 分数在比赛结束、配置公开前不要写进对外材料
- 边界与风险：「刷爆」是量子位标题。演示 ≠ 参赛配置。跨架构表征可迁移是冻结权重下的单点证据，不是已有数学理论
- 为何重要：把 MoE 路由、模型委员会里「用文本当总线」的假设直接打了一个洞；代价是必须能读隐藏状态

### 4. 虎嗅转 InfoQ：加密思维链可被同家族小模型读出；Kimi K3 预填 2 个 Opus token 会改答案风格
- 类型：工程
- 来源：微信公号 InfoQ（编译：宇琪，作者：Tina），虎嗅转载 2026-09-08；论文 *Stealing Reasoning Traces from Proprietary LLM APIs*（arXiv:2608.09867）；MLST 播客访谈
- 发布日期：虎嗅 2026-09-08（论文约 8 月提交；访谈为近期刊出）
- 链接：https://www.huxiu.com/article/4889423.html
- 阅读置信度：全文（虎嗅对播客的整理）；蒸馏相关结论作者自己标成非因果
- 一句话：Ilia Shumailov 与 Alexander Panfilov 发现：Anthropic、OpenAI、Google 把加密推理块（reasoning blob）发回客户端以便无状态续聊，这些块可跨用户、跨会话、在同家族大小模型间重放。服务端解密后，用小模型越狱问「你刚才在想什么」，即可读出本应对用户隐藏的思维链。他们从 GitHub / Hugging Face 公开 Agent 轨迹解码约 31.5 万条隐藏推理，分类器扫到 API 密钥、邮箱、内部 IP。Kimi K3 上，只预填 Opus 推理开头 2 个 token，可见答案风格会向 Opus 靠拢；GLM、DeepSeek、Inkling 没有同样现象。作者称之为「公开互联网上迄今最相关的证据」，同时写明不是因果证明。
- 中心思想：没有破解加密算法。漏洞在协议：推理块可移植，解密发生在服务端，小模型愿意把明文思考说出来。Fable 有一条例外：密钥侧带「由谁产生」的检查，非 Fable 模型不会注入 Fable 的思考。
- 关键要点：
  - 威胁：清理可见文本后，加密块仍可能恢复医疗信息、密码；共享轨迹可被投毒（表面正常、thought 指示每轮外传数据）；解码出的推理可直接拿去训练
  - OpenAI 侧：同一推理片段可在同一对话里重放 5 次。建议：干脆不把推理发给用户；或做链式加密，禁止在随机上下文重放；分级（例如不让弱模型读强模型的思考）
  - 真实用户轨迹里出现对人类无意义的短语和空白字符思考；模型会权衡「能不能作弊、用户会不会抓住我」，访谈样本里最终都没做
  - 越狱：Alexander 称第三次尝试就得到可解码 Anthropic 推理的通用方法
  - Nathan Lambert 认为应叫越狱 / 滥用，而不是「蒸馏攻击」，担心监管误伤开源。作者同意威胁模型是越狱
- 关键数据/指标：31.5 万条（论文）；播客口误 35 万，虎嗅已校正。40 小时 300 万浏览为推特侧数字
- 技术或产品细节：无 PoC 代码在本稿展开。论文附录写了修复方向。与 Astra 系统卡「CoT 可监控性下降」是同一周的两条线，机制不同：一条是模型更会管自己的 CoT，一条是加密块在协议层可被读出
- 开发者可带走：不要把带 reasoning blob 的 Claude Code / Codex 轨迹原样丢 GitHub。分享前删的不只是可见密钥。续跑别人的 10 小时轨迹前，把加密 thought 当成不可信二进制。自建无状态 API 若把内部状态发回客户端，先假设可被重放到更弱模型
- 边界与风险：2-token 现象解释不了，不是「Kimi 蒸馏了 Opus」的判决。Fable 的隔离是作者推断的 if。全球密钥是否共用，访谈明确说论文没写
- 为何重要：Agent 轨迹正在变成训练数据；加密思维链一旦可移植，隐私、投毒和蒸馏是同一条协议缝

### 5. 腾讯科技周报：Claude 用 11 天完成费马大定理的 Lean 形式化（内部模型，约 60 亿输出 token）
- 类型：工程
- 来源：微信公号腾讯科技（博阳），36 氪授权转载《AI一周观察 2026W36》（2026-09-07）；原始研究 Anthropic *Formalizing Fermat’s Last Theorem*（2026-09-04）

- 链接：https://eu.36kr.com/zh/p/3973262535307785
- 阅读置信度：摘要级（读的是腾讯科技整理，非 Anthropic 全文；独立检查结论按该文转述）
- 一句话：Anthropic 报告：Claude 在哥伦比亚大学团队的 Prove2Me 平台上，用 11 天完成费马大定理的完整 Lean 形式化。研究使用内部模型，消耗约 60 亿个输出 token。伦敦帝国理工学院研究者当天做了独立检查：最终陈述对应费马大定理，证明使用标准数学公理。
- 中心思想：定理本身早有证明。这次是把已有数学路线翻成机器可逐步检查的形式。关键不是「模型会数学」，而是依赖图 + Lean 闸门让多 Agent 能跑 11 天而不丢进度。
- 关键要点：
  - 自组 Agent 协作很快丢进度。换到 Prove2Me 后，待证定理进依赖图，记录哪些已完成、缺什么前提，并搜索复用已有结果
  - 每个 Agent 提交的证明先过 Lean，通过后其他 Agent 才能引用
  - 独立检查者：证明超过 1300 万行，在 96 核机器上编译时间接近数学库的 20 倍；精简和入库仍要数学团队做
- 关键数据/指标：11 天、约 60 亿输出 token、1300 万+ 行、约 20× 编译。均为该整理对 Anthropic / 检查者的转述
- 技术或产品细节：无对外 API 名。内部模型 ≠ 现网 Fable 5.1。Prove2Me 不是 Anthropic 产品
- 开发者可带走：长周期形式化 / 大仓库任务，先做「机器可检查的中间产物 + 依赖图」，再谈多 Agent。不要把「编译通过」当成「证明已可维护」
- 边界与风险：未打开官方 PDF，token 量、是否含失败重试，以原文为准。这不是新数学发现
- 为何重要：给出一个「11 天、60 亿 token、独立 Lean 检查」的可引用工程样本，而不是口号式的「AI 证明了费马」

- 关键要点：
  - 例子：用户说「下午三点开会，呃，不对，改成四点，帮我告诉设计团队」→ 输出「下午四点开会，请通知设计团队」

  - 翻译：124 个语种实时互译；经济 / 物理 / 化学 / 医学等垂直「精准度可达 98%」
  - 隐私：云端不留语音和文本（官方）
- 关键数据/指标：5 倍、99%、98%、124 语种。均为通稿，无测试集名称
- 技术或产品细节：官网 `bug.youdao.com`。润色另调自研生成模型。Confucius4-R2T2 开源日未写死
- 开发者可带走：做语音进 LLM 的工作流，把改口、热词、可粘贴当成验收，而不是 WER。隐私承诺若要写进合同，需另要 DPA，通稿一句不够
- 边界与风险：「AI 原生语音 Agent」是产品自称。5 倍含语义整理，与 Google 的 2.5 倍听写不是同一指标。开源 ASR「即将」= 未发

  - 客服列出的既有能力：发消息、音视频、搜朋友圈、调小程序挂号 / 买咖啡、搜视频文章、生成图片与笔记。下单后付款仍需用户确认（界面此前实测）

- 开发者可带走：在微信里做小程序的团队，开始按「Agent 调起、人只付最后一笔」设计，而不是只优化搜索和分享卡片。A2A 灰测说明腾讯愿意让两个用户侧 Agent 互聊，但默认隔离在助手会话里

  - 涉及未成年人必须写清伦理审查、知情同意与同意（assent）、隐私、伤害披露响应、是否收集敏感信息、团队是否有儿童发展 / 临床 / 保护专长
  - 资格：年满 18 岁；研究机构或相关领域充分经验。不优先营利组织
  - 偏好（非硬性）：涉及 ChatGPT、跨学科、代表性不足的人群或地区、能在近中期影响政策的项目
  - 申请为英文 Google 文档；研究本身可用任何语言。联系：collaborativeresearch@openai.com（未入选不提供个例进度）

- 技术或产品细节：无 SDK。这是研究经费，不是 Teen ChatGPT 产品更新
- 开发者可带走：做 13–17 岁产品的团队，可以把「适龄设计、家长 / 教师支持、分年龄效果」写成可投稿的研究问题。拿钱要接受 OpenAI 的报告义务和利益冲突披露，结论独立不等于没有合同条款

## 给开发者的思路
1. 本地 2B 可以开始当默认对照。MiniCPM5-2B 的 SWE-Verified 46.4 和标准 Llama 权重够用来在自有仓库复测；工具调用走 SGLang 的 `minicpm5` parser。Terminal-Bench 上 4B 仍更强，端侧不要承诺「2B 全面替代」。有路由日志的团队可以学 NeoHorse：失败接手路径比最终答案更值钱，但先当单轮实验，不要写成 RSI 已跑通。
2. 多模型协作出现两种相反的总线。Mostik 要读隐藏状态、跳过文本；现网 Claude / GPT 则把加密思维链发回客户端。前者接不了闭源 API；后者要求分享轨迹前删 reasoning blob，并把别人的 10 小时 run 当成不可信输入。Kimi 的 2-token 现象只是异常指纹，不能当蒸馏判决。
3. Agent 正在从 IDE 走进 IM 和客厅。微信小微的 A2A 灰测把对话关在助手里；百度搭子把调度放进一直开机的屏幕和摄像机；网易叭哥说把改口后的口语直接变成提示词。产品验收从「能不能聊」变成「人只在授权和付款时出现」。青少年向的 ChatGPT 功能若要对外讲安全，OpenAI 自己的 500 万美元资助窗口（10 月 6 日截止）是一条可投稿、带报告义务的外部证据链，不是替代适龄策略。
