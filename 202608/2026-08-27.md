### 2. 阿里通义发布 Qwen3.8-Flash，并开源 Flash-Next 权重
- 类型：工程
- 来源：IT之家 / 2026-08-26
- 发布日期：2026-08-26 20:39
- 链接：https://www.ithome.com/0/994/735.htm
- 阅读置信度：全文
- 一句话：通义发布 Qwen3.8-Flash；同步开源 Qwen3.8-Flash-Next，文中称 Next 架构是 Qwen4 系列雏形。
- 中心思想：多模态 MoE。主模型 125B，另有 51B N-gram Embedding，每 token 激活 6B。原生上下文 262,144 tokens，可用 YaRN 扩到 1M。IT之家称训练成本约为 Qwen3.7-Plus 的九分之一。
- 关键要点：
  - Attention：GDN + QSA；文中称 1M 上下文下 QSA Attention Kernel 在 Prefill / Decode 最高约 7.6× / 4.9× 加速（厂商口径）
  - Residual：Gated Residual，4 条并行分支；残差状态支持 FP8
  - Embedding：51B N-gram，可放 Host Memory，异步 Prefetch
  - Optimization：Muon Optimizer，并重拟合 Scaling Law
  - Base：文中称在 14 个 benchmark 里 8 个最优（列举含 MMLU-Pro、SWEBench-Pretrain、MMMU 等）
- 关键数据/指标：125B + 51B Embedding / 激活 6B；API 定价（IT之家称来自官方）每百万 tokens 输入 1 元、输出 3 元；权重开放时间文中写北京时间 8 月 26 日 23:00
- 技术或产品细节：HF / ModelScope 开源，含 FP8；Flash-Next 默认 1M 上下文并内置官方工具；技术博客与 tech report 见文内链接
- 开发者可带走：把 `qwen3.8-flash`（或官方最终 API 名）和开源权重各做一条评测路径：API 成本账 + 本地/私有化部署可行性。
- 边界与风险：加速倍数与「8/14 最优」为报道转述官方结果；「千问办公」同日产品化能力需另测。
- 为何重要：与 GLM Flash 同日段，形成可对比的低激活成本开源选项。

## 给开发者的思路
1. 模型侧：用同一套仓库任务对比 GLM-5.3-Flash 与 Qwen3.8-Flash，记录成功率、时延、每任务成本；数字只采用官方价目与自测，不采口头倍数。
2. 基础设施侧：向云厂商要 Agent 向指标（长上下文多轮、交互 tokens/s），并问清结果是否第三方审核。
3. 产品侧：办公 Agent（如豆包工作）先做权限与审计试点，再扩到控电脑/云电脑等高权限能力。
